# Installation

---

This goes over how to install Hydrogen

:::tabs
==Wally
In your `wally.toml`, add the following to your dependencies.

```toml
hydrogen = "teamhydrogen/hydrogen@0.4.0"
```

==Pesde
Run this in your CLI.

```sh
pesde add teamhydrogen/hydrogen
```

==LPM
Run this in your CLI.

```sh
lpm add teamhydrogen/hydrogen
```
